# HSE RecSys Challenge 2026

Рекомендации фильмов (top-10 на пользователя), метрика recall@10.
Финальная модель — ансамбль глобальной и локальной EASE с тремя направленными ridge-моделями,
**0.2480** на публичном лидерборде.

## Файлы

| Файл | Что внутри |
|---|---|
| `eda.ipynb` | разведочный анализ данных и гипотезы |
| `REPORT.md` | отчёт: все проверенные гипотезы, эксперименты, сабмиты и выбор финальной модели |
| `solution.ipynb` | финальное решение: валидация на пяти временных срезах, обучение, `submission_improved.csv` |
| `models/` | снепшоты пяти обученных матриц (`.npz`, по ~51 МБ) |
| `data/` | данные соревнования |

## Запуск

```bash
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace solution.ipynb   # или Run All в Jupyter
```

Полный прогон — около 3 минут на CPU. При `USE_SNAPSHOTS = True` (по умолчанию) финальные матрицы
загружаются из `models/`, если они там есть; иначе обучаются заново (~30 с) и сохраняются.
В обоих случаях сабмит одинаковый.

Снепшоты весят ~255 МБ суммарно. Если они не хранятся в репозитории, их можно скачать по ссылке
<!-- вставьте ссылку на Google Диск / Яндекс Диск --> и положить в `models/`; без них ноутбук просто обучит модели заново.
